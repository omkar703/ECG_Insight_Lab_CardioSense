# Sample Data Manifest & Licensing

This directory stores small, lightweight, licensed test images and data manifests for integration testing and demo mode.

## Privacy and Data Governance Policy

- **Zero PII Policy:** Never commit identifiable patient health records, hospital scans with patient names, MRNs, dates of birth, or clinical metadata to this repository.
- **Sample Attribution:** Any external benchmark ECG records incorporated in later phases must be drawn from open-access sources (such as PhysioNet PTB-XL under CC BY 4.0) with explicit attribution.
- **Demo Watermarking:** All sample data presented in application interfaces is explicitly tagged with `DEMO / SAMPLE` watermarks.
